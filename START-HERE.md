# nope: Start Here

**This repository is public.** Nope is a Chrome extension, backend and dashboard MVP that adds friction at checkout for categories a user chooses to block. It is a side project, not ATTN Labs client work. It replaced the earlier `tollbooth` repo in March 2026.

## Read in this order

1. `README.md`: structure and quick start.
2. `PRD.md`: product requirements.
3. `extension/`, `backend/`, `dashboard/`: the code.
